# Voice Assistant 🤖

A Python-based Voice Assistant that can perform basic tasks using voice commands such as opening applications, searching the web, and responding through speech.

---

## Features
- Voice command recognition
- Text-to-speech response
- Open websites and applications
- Search information on Google
- Tell current time and date
- Interactive voice responses

---

## Technologies Used
- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- Webbrowser
- Datetime
